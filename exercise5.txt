Declare CourseNumber

Display "Enter a course number. The course number must be an integer between 1,000 and 9,999."
Input CourseNumber

While CourseNumber < 1000 OR CourseNumber > 9999 OR CourseNumber % 2 != 0
    Display "Invalid course number. Please enter a course number between 1,000 and 9,999 that is even."
    Input CourseNumber
End While

Display "You entered a valid course number: " + CourseNumber
